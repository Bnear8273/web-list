# 随机选择器

一个很简单的本地随机选择器：把候选项写进清单，纠结的时候随机挑一个。支持多个清单，每个清单的选项和抽选互不影响。纯静态网页，无需后端，数据保存在浏览器的 `localStorage`，可以直接部署到 GitHub Pages。

## 功能

- 创建多个清单，随时切换；每个清单独立保存选项，抽选也互不影响
- 清单较多时，可用左右箭头、鼠标滚轮或横向滑动切换清单
- 新建、重命名、删除清单（至少保留 1 个）
- 添加选项，自动拦住空名称和重名
- 每个选项都可以单独禁用或启用抽选，禁用后仍保留在清单里
- 支持「全部禁用」「全部启用」，快速控制当前清单的参与范围
- 点击铅笔图标就地修改选项名称
- 点击垃圾桶图标，确认后删除
- 一键随机抽选，只在已启用的选项中挑选；有多个选项时不会连续抽到同一个
- 刷新或重新打开页面后，清单和禁用状态仍然保留
- 当前清单可一键复制到剪贴板，也可以从剪贴板粘贴导入
- 粘贴时可选覆盖当前清单，或追加并自动去重
- 手机和桌面端自适应

## 本地预览

项目没有构建步骤，也不需要安装依赖。直接打开 `index.html` 即可，或者启动一个静态服务器：

```sh
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 部署到 GitHub Pages

项目已推送到 `main` 分支，并在仓库 **Settings → Pages → Build and deployment** 中使用 **Deploy from a branch**，选择 `main` 分支和 `/ (root)` 目录。

所有文件都是静态文件，资源路径均使用相对路径，放在项目子路径下也能正常打开。由于主仓库已绑定 `github.bnear8273.top`，本项目自动发布在：

<https://github.bnear8273.top/web-list/>

## 复制与粘贴导入

页面底部的「复制」会把当前清单的全部选项按每行一个的格式写入剪贴板；「粘贴」会读取剪贴板，并让你选择导入方式：

- **覆盖清单**：用粘贴内容替换当前清单的全部选项，其他清单不受影响
- **追加并去重**：保留当前清单的现有选项，只追加新名称；重复名称会自动跳过

```text
看书
散步
看电影
```

粘贴时也会兼容旧版导出的 JSON 备份格式。如果浏览器拒绝访问剪贴板，粘贴按钮会退回到手动粘贴输入框。

## 数据说明

- 存储键：`random-picker.lists.v1`
- 每个清单的选项、禁用状态会一起保存。
- 从旧版单清单数据（`random-picker.items.v1`、`what-to-eat.dishes.v1`）升级时，会自动迁移成一个名为「我的清单」的清单。
- 数据只存在当前浏览器的当前站点下，不会上传到任何服务器。
- 本地预览（`localhost`）和线上 Pages 域名的数据互相独立。
- 清除浏览器站点数据会丢失全部清单。

## 文件结构

```text
.
├── index.html              # 页面
├── styles.css              # 样式
├── app.js                  # 多清单管理、清单增删改、随机抽取、本地存储
├── favicon.svg             # 站点图标
└── README.md
```

> 修改 `app.js` 或 `styles.css` 后，记得同步更新 `index.html` 里资源地址的 `?v=` 版本号，避免浏览器混用旧缓存。
